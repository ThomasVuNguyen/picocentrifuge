Swinging-bucket design, four 15 mL conicals, generated in Fusion 360 by an agent off a
Jira ticket. Complete on paper: parametric file, STEP, nine STLs, assembly drawing, BOM,
and a reproducible Fusion API build script. Never built.

Design point was 150 mm tube radius, 1545 rpm, 400.3 x g, which needed a containment
vessel with 466 mm clear inside diameter. That is a restaurant stock pot.
